# Источники геоданных

`water-objects.json` содержит производную выгрузку © OpenStreetMap contributors от 15 ноября 2026 года. Выгрузка доступна по лицензии [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Исходные идентификаторы десяти озёр перечислены в [спецификации](../../../docs/product-spec.md). [Условия OpenStreetMap](https://www.openstreetmap.org/copyright)

Озёра получены через Nominatim Lookup с `polygon_geojson=1` и `polygon_threshold=0`. Область Псковского озера включает залив Вярска в Эстонии. Она взята из общего контура Чудско-Псковского озера (1318060) после вычитания Чудского (17388038) и Тёплого (17388039) озёр. Из оставшихся областей выбрана та, у которой наибольшее перекрытие с исходным контуром Псковского озера (17388042). [Общий контур OpenStreetMap](https://www.openstreetmap.org/relation/1318060) · [Описание залива Вярска, Департамент здоровья Эстонии](https://www.terviseamet.ee/sites/default/files/documents/2024-09/varska_sanatooriumi_supluskoha_suplusvee_profiil.pdf)

Для Невы из линий собраны внешние и внутренние кольца, затем три полигона объединены. Контуры водоёмов упрощены с допуском 0,000025° с сохранением топологии. API отдаёт для карты те же области, по которым оценивает попадание. [2599821](https://www.openstreetmap.org/relation/2599821) · [1114249](https://www.openstreetmap.org/relation/1114249) · [1648985](https://www.openstreetmap.org/relation/1648985)

`reference-lines.geojson` содержит береговые линии и сухопутные границы Natural Earth 5.1.2 (1:50 млн), обрезанные по охвату карты. Эти обзорные линии не участвуют в оценке ответа. [Исходные векторы](https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2/geojson) · [Условия Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/)

Рельеф подгружается из Esri World Hillshade. Атрибуция поставщиков указана в ответе API. [Описание и условия сервиса Esri](https://services.arcgisonline.com/arcgis/rest/services/Elevation/World_Hillshade/MapServer)

`countries.json` содержит контуры стран и территорий Natural Earth из релиза 5.1.2. Из слоя Admin 0 Countries (1:50 млн) взяты идентификатор `ADM0_A3`, русское название `NAME_RU`, цвет `MAPCOLOR13` и геометрия. Из слоя Populated Places (1:10 млн) взяты русские названия столиц с `ADM0CAP=1` по тому же `ADM0_A3`. Где нет перевода, используется название из исходника. Обзорные границы отражают подход Natural Earth к фактическому контролю территорий. [Контуры](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_50m_admin_0_countries.geojson) · [Населённые пункты](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_10m_populated_places.geojson) · [Методика Natural Earth](https://www.naturalearthdata.com/about/) · [Условия использования](https://www.naturalearthdata.com/about/terms-of-use/)

В подписях обновлены названия столиц Казахстана и Экваториальной Гвинеи. Для Кот-д’Ивуара указана политическая и административная столица Ямусукро. [Казахстан](https://www.gov.kz/article/232335?lang=en) · [Экваториальная Гвинея](https://www.guineaecuatorialpress.com/noticias/decreto_ley_por_el_que_se_declara_la_ciudad_de_la_paz_djibloho_capital_de_la_republica_de_guinea_ecuatorial) · [Кот-д’Ивуар](https://diplomatie.gouv.ci/informations-utiles/presentation-de-la-c%C3%B4te-d-ivoire)

`country-continents.json` группирует страны и территории по полю `CONTINENT` того же слоя Natural Earth. Для океанических территорий используется регион `REGION_UN`. Россия и Турция включены в Европу и Азию.

`world-water-objects.json` содержит подборку озёр и водохранилищ Natural Earth 5.1.2 (1:50 млн). Обзорные слои суши и границ мира в `frontend/public/` упрощены до 0,014°. [Исходные векторы Natural Earth](https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2/geojson)

Пять антарктических озёр взяты из High resolution Antarctic lakes dataset (7.3), Gerrish, L., Fretwell, P., & Cooper, P. (2020), UK Polar Data Centre. Контуры переведены из EPSG:3031 в WGS84 и упрощены с допуском 12 м. © Scientific Committee on Antarctic Research, CC BY 4.0.
